## 🚀 Instalação Rápida via Terminal (CMD / PowerShell)

Para instalar ou atualizar o aplicativo diretamente sem precisar abrir o navegador, abra o **Prompt de Comando (CMD)** ou **PowerShell** e cole o comando abaixo:

```cmd
powershell -Command "[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12; Invoke-WebRequest -Uri '[https://github.com/JulyMount/Youtube-Downloader/releases/latest/download/YouTube-Downloader-Setup.exe](https://github.com/JulyMount/Youtube-Downloader/releases/latest/download/YouTube-Downloader-Setup.exe)' -OutFile '%TEMP%\yt-setup.exe'" && "%TEMP%\yt-setup.exe"
```

> 💡 *O comando acima descarrega a versão mais recente diretamente das Releases do GitHub e inicia o instalador automaticamente.*

## 📦 Download Manual

Se preferir baixar o arquivo executável tradicionalmente:

1. Acesse a seção de **[Releases](https://github.com/JulyMount/Youtube-Downloader/releases/latest)**.
2. Baixe o arquivo **`YouTube-Downloader-Setup.exe`**.
3. Execute o instalador no seu Windows.

## ✨ Recursos

- 🎵 **Download de Áudio:** Converte automaticamente para **MP3 (320kbps)** em alta qualidade.
- 🎥 **Download de Vídeo:** Baixa em **MP4** na melhor resolução disponível.
- 🎬 **Compatibilidade Profissional:** Vídeos convertidos nativamente em **H.264 / AAC**, totalmente compatíveis com **Adobe After Effects**, **Premiere Pro** e outros editores.
- ⚙️ **Modo Avançado (Estilo Snaptube):** Escolha manualmente resoluções específicas (1080p, 720p, 480p, etc.).
- 🎨 **Interface Moderna:** Design escuro orgânico em gradiente Ciano/Violeta com bordas arredondadas e barra de título personalizada.
